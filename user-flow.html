Stay in sync

auto-ticket to owner
Auto-ticketing. When a dataset is delayed or fails validation, DataGov automatically creates a ticket and assigns it to the data owner. Users never manually turn an alert into a ticket — they just monitor and resolve.
Status flows
Data Source Status Online→ Degraded→ Offline Bug — Bug is a parallel error state; delay / failure auto-opens a ticket
Ticket Status Open→ In Progress→ Validating→ Resolved→ Closed — “Mark Resolved” triggers system validation (Validating)

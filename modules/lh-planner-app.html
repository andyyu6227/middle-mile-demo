Sealing ends the review. The schedule stops being editable and starts being used: from the next 04:00 run the background loop picks it up on its own, with no separate publish step.
MATCHINGEvery night the run measures each day’s forecast against the design volume of every sealed version for that SOC × leg, and takes the closest one. This version wins the days it is closest to.
FORECASTEvery forecast refresh re-checks those days against it and re-maps them if the level moves.
SCHEDULEIts trips are the schedule version data written to the SPX Master Schedule for the days it wins. Carrier fields are never touched.
VERSION SETIt joins the task list under Status = Sealed — the set the matcher is allowed to choose from.
